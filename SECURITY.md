# Sécurité

Ce dépôt ne contient que du Markdown : aucun script, aucune clé. Le skill modifie l'interface sur laquelle tu le lances : travaille sur une branche et relis les changements avant de les garder.

Un problème de sécurité ? Ne l'ouvre pas en issue publique : utilise **Security → Report a vulnerability** sur la page du dépôt.
